# 홍보 자료

`kit.html`은 홍보 키트 페이지입니다. 계정 프로필, 첫 게시물 9개와 글, 올리는 날짜, 해시태그, 커뮤니티 글, 기관 메일, 연락처가 들어 있고, 브라우저로 열면 됩니다.

| 폴더 | 내용 |
|---|---|
| `images/` | 인스타 게시물(1080×1350), 스토리·릴스 커버(1080×1920), 프로필(1080×1080), 소개서에 쓰는 게임 화면 |
| `video/reel-howto.mp4` | 릴스·쇼츠·틱톡용 26초 영상(1080×1920, 소리 없음) |
| `brochure/` | 교사·과학관·천문대용 A4 두 쪽 소개서. `brochure-ko.html`을 브라우저로 열어 `[사이트 주소]`, `[연락받을 이메일]`을 고친 뒤 인쇄 → PDF로 저장하면 새 PDF가 됩니다 |

- 예시 작품 카드는 게임의 "이미지 저장"과 같은 코드(`src/sky/card.js`)로 만들었고, 작가 이름은 공식 계정인 "다시 그린 하늘"로 넣었습니다.
- 게임 화면 속 다른 닉네임과 순위는 화면 예시입니다.
